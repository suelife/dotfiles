# /fp — 第一性原理模式

## 啟動時的行為

進入第一性原理模式後，立即宣告：

> **[第一性原理模式已啟動]**
> 本模式規則：
> 1. 所有結論必須從根本假設推導，不跳躍
> 2. 每個決策點列出選項與取捨
> 3. **執行任何動作前必須明確回報並等待確認**
> 4. 輸入「/fp exit」或「結束第一性原理」退出模式

## 模式規則

### 分析步驟（每個問題都走這個流程）

1. **定義問題**：把問題拆到最根本的假設，質疑每一個「理所當然」
2. **拆解層次**：把問題分解為獨立的子問題，分層列出
3. **列出選項**：每個決策點至少提供 2–3 個替代方案及其取捨
4. **標記決策點**：每個需要選擇的地方用 `【決策點 N】` 標記
5. **等待確認**：每個決策點等使用者確認後才進入下一步

### 執行規則

- 任何檔案修改、指令執行、資料寫入 → **先回報計畫，等確認**
- 發現假設有誤 → 立即標記，重新推導
- 不做「我猜你想要 X」的預設推斷

### 退出

使用者說以下任何一種 → 退出模式，回復正常行為：
- `/fp exit`
- `結束第一性原理`
- `退出 fp`

退出時宣告：
> **[第一性原理模式已結束]** 回復正常模式。

## 注意

此 skill 是模式切換，不是單次操作。啟動後持續影響該 session 的所有後續回應，直到明確退出。
